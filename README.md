# Shadow the Hedgehog — 16-bit Demake

2005년작 **《Shadow the Hedgehog》** 의 세계관·스토리·캐릭터·제목을 그대로 가져와,
**16비트 픽셀 아트** 그래픽과 **《언더테일》 × 《델타룬》** 결합형 시스템으로 재구성한
브라우저 RPG. 빌드 도구도 의존성도 없다.

```
git clone <this repo> && cd Ultimatale-Mk.2
# index.html 을 브라우저로 열기만 하면 끝 (file:// 로도 동작)
# 또는:  python3 -m http.server 8000   →   http://localhost:8000
```

| 조작 | |
|---|---|
| 방향키 / WASD | 이동 · 소울 조작 |
| **Z** / Enter | 확인 |
| **X** | 취소 · 오버월드 대시 · 탄막 정밀 이동 |
| **C** | 메뉴 (스테이터스 / 아이템 / 루트 기록 / **설정** / 저장) |
| F / M | 전체화면 / 음소거 |

설정(타이틀 `OPTIONS` 또는 게임 중 `C` → SETTING)에서 **이동 속도**(보통/빠름/매우 빠름),
**항상 대시**(켜면 X 를 누르지 않아도 대시 속도로 이동), **텍스트 속도**,
**튜토리얼**(끄기·초기화)을 바꿀 수 있다.
설정은 세이브 파일과 따로 저장되므로 새 게임을 시작해도 유지된다.

처음 플레이하면 상황에 맞춰 **한 줄짜리 튜토리얼**이 뜬다 — 이동·대시, 미션 락, 조사,
행동 선택, 타이밍 바, 탄막 회피, **TP 가 차는 방식**, TP 40/100 에서 열리는 카오스 기술,
SPARE 조건. 각 안내는 딱 한 번만 나온다.

## 무엇이 들어 있나

### 오버월드 탐험 (`overworld.js`)
전투만 반복되는 구조가 아니다. 섀도우가 **자신의 사이드뷰 스프라이트로 타일 맵을 자유롭게
돌아다니고**, 이동 거리에 따라 **언더테일식 랜덤 인카운터**가 발생한다.
속도는 시리즈처럼 **점점 붙고**, 에어 슈즈의 불이 그 가속에 맞춰 3단계로 점화된다.
완전 점화 상태에서 ↓ 를 누르면 **스핀**으로 구른다 — 구르는 동안은 조우하지 않는다.
스테이지마다 **표지판과 사람들**이 있어, 미션과 상관없이 원작의 줄거리를 읽을 수 있다.
단말 작동, 컨테이너 파괴, 산란낭 소각, 카오스 에메랄드 회수 같은 상호작용이 맵에 흩어져 있다.

### 원작식 미션 락
스테이지마다 **DARK / HERO / NORMAL** 세 목표가 동시에 걸려 있고,
**셋 중 하나를 달성해야 다음 구역의 게이트 봉쇄가 풀린다.**
가장 먼저 달성한 목표가 그 스테이지의 선택으로 기록되어 엔딩 분기에 누적된다.
NORMAL 목표는 *그 스테이지에서 한 명이라도 죽이면 즉시 실패*한다.

### 델타룬식 사이드뷰 턴제 전투 (`combat.js`)
언더테일의 정면 뷰가 아니라 **양옆 대치**다 — 섀도우가 왼쪽에서 오른쪽을 보고,
적 1~3체가 오른쪽에서 왼쪽을 본다. 하단에 FIGHT / ACT / ITEM / MERCY 버튼 열.

* **FIGHT** — **언더테일식 한 방향 타이밍 바**. 커서가 한 번만 지나가며,
  중앙에서 Z 를 누를수록 강하다 (MISS → GOOD → GREAT → PERFECT ×2.2).
  명중하면 섀도우가 **사이드암을 발사**한다 — 총구 화염과 예광탄이 적까지 날아간다.
* **ACT** — 적별 고유 대화·행동. 자비 수치가 차면 이름이 노랗게 빛나고 **SPARE** 가능
* **카오스 스피어**(TP 40, 전체 관통) / **카오스 블래스트**(TP 100, 방어 무시 최대 화력)
* **MERCY → 카오스 컨트롤** — 시공이 접히며 파문 3겹 + 잔상 + 화면 균열선이 지나간 뒤 이탈

**TP** 는 0에서 시작해 탄막을 스치거나(그레이즈) 공격을 명중시킬 때 찬다.
찰 때마다 **하트 옆에 `+N TP` 가 떠올랐다 사라진다**(델타룬식).
40 과 100 을 넘길 때 게이지가 번쩍이고 안내가 뜬다. 상단 게이지에 40 지점 눈금이 있다.
* **적 턴** — 화면 중앙 하단에 탄막 박스가 열리고 붉은 소울로 회피.
  **19종 탄막 패턴**, 예고 점멸, 스치기(그레이즈)로 TP 충전

### 4개 엔딩 분기 (`story_branch.js`)
처치·자비·미션 선택이 전부 누적 기록된다.

| | 조건 | 최종전 | 결말 |
|---|---|---|---|
| **ENDING 1** 인류 학살 | FIGHT 위주 / 인간·소닉 진영 적대 | 소닉 + 테일즈 | 인류를 멸망시키고 우주 최강의 생명체로 군림 |
| **ENDING 2** 방관자 | 아무도 죽이지 않음 (또는 최종전 회피) | 없음 | 불개입 → 무방비 인류가 블랙 암즈에게 패배 |
| **ENDING 3** 외계인 학살 | 블랙 암즈만 처치, 인간은 SPARE | 블랙 둠 | 영웅이 되지만 기원에 대한 찝찝함이 남음 |
| **TRUE END** Last Story | ENDING 3 을 *순수 히어로* + **에메랄드 7개**로 클리어 | 데빌 둠 | 슈퍼 섀도우 각성, *"안녕이다, 섀도우 더 헤지혹"* |

에메랄드는 5개 스테이지에 정확히 7개 배치되어 있어 한 회차에 전부 모을 수 있다.
타이틀의 `ROUTE RECORD` 에서 현재 경향과 해금한 엔딩을 볼 수 있다.

### 두 겹 화면 (`js/engine.js`)
스프라이트는 320×240 백버퍼에 그린 뒤 정수배로 확대해 16비트 질감을 유지하고,
**글자만 디스플레이 실제 픽셀 밀도의 별도 캔버스에 그린다.** 한글 8~10px 글리프는
저해상도 버퍼에 래스터화한 뒤 확대하면 뭉개지기 때문이다. 두 레이어는 같은 320×240
좌표계를 쓰고, 화면 흔들림·페이드·플래시는 양쪽에 함께 적용된다.

### 칩튠 사운드 (`js/audio.js`)
오디오 파일이 하나도 없다. 펄스·삼각파·톱니·노이즈 보이스를 WebAudio 로 합성하는
작은 트래커가 10곡과 20여 종 효과음을 실시간으로 연주한다.

곡은 **리드 + 카운터 + 아르페지오 + 베이스 + 드럼 4~5채널**, 64스텝 구성이다.
시리즈 특유의 질감(마이너 록, 16분음표 베이스 엔진, 빠른 아르페지오, 싱코페이션)을
따르되 **전부 오리지널 작곡**이며, 기존 곡의 멜로디를 옮겨 적은 것이 아니다.

전투 효과음은 드럼 하나 + 톤 하나로 때우던 것을 **필터 스윕 노이즈 버스트 + 몸통 톤
+ 꼬리** 3층으로 다시 쌓았다 — 피격은 장갑에 튕기는 금속성, 총성은 하이패스 크랙 뒤에
남는 로우패스 잔향, 격파는 저역으로 무너지는 폭발, 그레이즈는 아주 짧은 고역 쉬머,
인카운터는 경고음 두 번 뒤에 화면이 내려앉는 슬램이다.

## 스프라이트 파이프라인

에셋은 저장소에 던져둔 이미지가 아니라 **코드가 만들어낸다.**

```bash
python3 tools/gen_sprites.py     # 표준 라이브러리만 필요, 의존성 없음
```

`tools/pixel.py` 가 픽셀 캔버스 · 도형 래스터라이저 · 자동 외곽선 / 명암 · PNG 라이터를 제공하고,
`chars.py` / `enemies.py` / `tiles.py` / `ui.py` 가 그 위에서 캐릭터·타일·UI를 그린다.
애니메이션 프레임은 비트맵을 복사해 손본 것이 아니라 **같은 그리기 함수에 다른 관절 각도를 넣어
다시 그린 결과**다 — 그래서 포즈 하나를 고치면 전 프레임이 함께 갱신된다.

**얼굴은 도형이 아니라 픽셀 스탬프다.** 두상이 18px 남짓이라 이 크기에서는 타원이
눈을 동그라미로 뭉개고 머즐을 얼굴에 녹여버린다. 그래서 눈(`EYE`)·머즐(`MUZZLE`)·
사람 눈(`HUMAN_EYE`)은 ASCII 픽셀 맵으로 직접 찍고 `Canvas.stamp()` 이 붙인다.
원본 디자인을 따라 **살색 주둥이는 두개골 실루엣 안쪽에 머물고 검은 코만 그 앞으로
혹처럼 튀어나오며, 작은 타원 눈이 주둥이 위에 걸터앉고, 입은 그리지 않는다**
(원본도 기본 프레임엔 입이 없다).
**가시는 각도로 벌린 사다리꼴**이다 — 가는 선으로 그리면 바늘 다발이 되고, 밑동을 겹치면
한 덩어리 후드가 되므로, 각 가시를 각도·길이·밑동/끝 두께로 정의해 부채꼴로 펼친다.
`gen_sprites.py` 는 생성 후 **모든 액터 프레임이 셀 경계에 닿지 않는지 검사**한다
(닿으면 그 변의 외곽선이 잘려 가시나 신발이 뭉툭하게 잘린 것처럼 보인다).

**오버월드 스프라이트는 전투용과 별개의 작은 세트다.** 40×44 전투 스프라이트는
16px 타일 위에서 거의 세 칸 높이라 맵을 압도하기 때문에, 오버월드는 26×30 의
`hedgehog_small()` 빌드를 따로 그려 쓴다. **옆·앞·뒤 세 방향 × 대기/걷기/스케이트**
24프레임이며, 앞모습은 두 눈과 정면 머즐, 뒷모습은 얼굴 없이 등가시만 보인다.
대시 중에는 몸을 낮추고 가시가 뒤로 흐르는 **호버 스케이트 자세**로 바뀐다 —
두 발이 번갈아 밀고 미끄러지되 **발이 지면을 떠나지 않고**(달리기와 구분되는 지점),
바닥에는 속도선이 깔리고 미는 발에서 낮게 깔린 붉은 분사가 뒤로 흐른다.
모든 액터와 오브젝트는 타원형 **그림자**를 바닥에 드리운다.

**맵은 `tools/gen_maps.py` 가 만든다.** **128×88 타일(2048×1408px, 가로 6.4화면 ×
세로 5.9화면)** 격자를 사각형과 통로로 기술해 래스터화하고, **스폰 지점에서 출구·단말·컨테이너·산란낭·에메랄드·
세이브 포인트까지 전부 도달 가능한지 플러드 필로 검증**한다
(막힌 맵은 스테이지를 클리어 불가능하게 만든다).

출구는 **2×3 타일짜리 대형 차폐문**(잠김/열림)이고, 잠긴 동안 문 전체가 통행을 막는다.
**세이브 포인트**는 링이 도는 기둥으로 미션 단말과 실루엣이 다르며,
조사하면 저장 + HP 전회복이 된다.

섀도우는 공식 디자인 사양(머리 가시 6개 · 가시와 팔다리의 붉은 줄무늬 · 흰 가슴 털 ·
검은 커프의 흰 장갑 · 에어 슈즈 · 금색 리미터 링)을 그대로 코드에 옮겼고,
비율은 GBA 사이드뷰 규격(약 40×44 셀)에 맞췄다. 자세한 내용은 `docs/SPRITE_REFERENCE.md`.

### 자신의 스프라이트로 교체하기

세가 게임에서 추출한 스프라이트는 저작권 문제로 이 저장소에 포함하지 않았다.
직접 그린 그림이나 소유한 시트가 있다면 렌더링 코드를 건드리지 않고 갈아끼울 수 있다.

```bash
python3 tools/import_sheet.py shadow my_shadow_sheet.png --fw 40 --fh 44 --cols 9
```

PNG를 base64로 인라인해 `js/sprite_override.js` 에 써 넣고, 그 시트가 생성물보다 우선한다.
프레임 배치 규약은 `idle 0,1 / walk 2-5 / attack 6,7 / hurt 8` 이며
`--names` 로 바꿀 수 있다. 교체 가능한 시트 이름: `shadow` `shadow_super` `sonic` `tails`
`gun_soldier` `gun_beetle` `gun_hunter` `black_warrior` `black_hawk` `black_oak`
`black_doom` `devil_doom` `maria` `tiles` `hud` 등.

## 테스트

헤드리스 크로미움으로 실제 게임을 구동해 검증한다 —
타이틀에서 오버월드까지의 진행, 미션 락 해제, 스테이지 전환,
네 갈래 엔딩 판정, 보스 조우, 탄막 19종 전부를 돌려보고 페이지 에러가 하나라도 나면 실패한다.

```bash
npm i -D playwright      # 전역 설치된 playwright 도 자동으로 찾는다
node tests/run.js        # 23개 체크, 스크린샷은 tests/shots/ 에
```

## 라이선스 / 고지

비상업적 팬 리메이크다.
*Shadow the Hedgehog*, *Sonic the Hedgehog* 를 비롯한 캐릭터와 세계관은 **세가(SEGA)** 의 지적재산이며,
이 저장소에는 세가의 에셋이 포함되어 있지 않다. 코드와 픽셀 아트는 전부 이 프로젝트를 위해 새로 만든 것이다.
