# assets/

`sprites/` 안의 PNG 는 전부 `tools/` 의 파이썬 스크립트가 **생성한 결과물**이다.
손으로 수정하지 말고 소스(`tools/*.py`)를 고친 뒤 다시 생성할 것.

```
python3 tools/gen_sprites.py
```

이 명령은 `assets/sprites/*.png` 와 `js/sprite_data.js`(같은 이미지를 base64 로 인라인한 것)를
함께 갱신한다. 게임은 `js/sprite_data.js` 쪽을 읽으므로 서버 없이 `file://` 로도 동작한다.

## 저작권

여기 있는 이미지는 전부 이 저장소를 위해 새로 만든 오리지널 픽셀 아트다.
세가(SEGA) 게임에서 추출한 스프라이트는 **한 장도 포함되어 있지 않다.**
캐릭터 디자인 자체(섀도우, 소닉 등)는 세가의 지적재산이며,
이 프로젝트는 비상업적 팬 리메이크다.
